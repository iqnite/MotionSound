# Yeetme!

The only app you will ever need on your phone.

[**Install**](https://github.com/iqnite/MotionSound/releases) | [**Learn more**](#description)

![App icon](.github/readme_images/icon_round.webp)

## Description

Yeetme! is an Android app that makes wacky sounds when you move your phone in specific ways. It has multiple modes, such as Gun, Bomb, Speed, and more.

## Credits

Some sound effects were taken from [Pixabay](https://pixabay.com/sound-effects/).

AI tools were used to generate boilerplate code and for debugging. All images in the app, as well as the app's logo, were hand-drawn by me. No texts were generated by AI.
